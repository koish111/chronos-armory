## 安装要求

### 必需组件
- **Minecraft版本** 1.21.1
- **NeoForge版本** 21.1.186 或更高版本

### 必须前置
- [动画前置] GeckoLib
- [动作前置] Better Combat

## 安装指南

1. 确保已安装正确版本的 NeoForge
2. 下载最新版本的 [模组名称]
3. 将模组文件放入 `.minecraft/mods` 文件夹
4. 启动游戏
